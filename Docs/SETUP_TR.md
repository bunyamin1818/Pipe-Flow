# Unity projesini açma

1. Proje klasörünü ZIP'ten çıkar ve Unity Hub'dan **Add project from disk** ile `PipeFlow` klasörünü seç.
2. Unity açıldığında `Assets/Scenes/Main.unity` dosyasını aç ve **Play** tuşuna bas.
3. **Pipe Flow > Validate Levels and Assets** ile görseller ve bölüm verilerini kontrol et.
4. Yeni ilerleme testi için **Pipe Flow > Reset Local Test Progress** kullan. Bu komut yalnızca bu bilgisayardaki test kaydını siler.
5. Android için Unity Hub'dan Android Build Support, SDK/NDK Tools ve OpenJDK modüllerini kur. **Pipe Flow > Prepare Unity Project** ardından Android platformunu seçerek test APK'sı oluşturabilirsin.

**Yayınlamadan önce:** Paket kimliğini (`com.example.pipeflow`), uygulama ikonunu, mağaza görsellerini, imzalama anahtarını, performansı ve görsel/ses kullanım haklarını kontrol et.
